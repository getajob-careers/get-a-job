# Full design audit — 2026-07

**Owner:** design lane · **Date:** 2026-07-23 · **Bar:** "real product, not
vibe-coded" (the 9-rule `design-craft` bar).

Findings only — **no fixes applied.** Eli triages this list before any fix PRs.
Each finding carries a **severity**, a **flag state**, a `file:line` evidence
pointer, and a one-line fix sketch.

## How to read this

- **Severity** — `blocker`: a real user (or a demo) sees it as broken or
  embarrassingly unpolished — visual breakage/overflow, WCAG-AA contrast failure,
  a non-functional-looking or dead control, a fabricated-progress/honesty
  violation, or a data surface with no loading/empty/error handling it can hit.
  `degraded`: noticeably rough or inconsistent but usable. `polish`: a nit.
- **Flag state** — prod default is **flag-off** (`?next=0` / no flag): what real
  users see **today** is the legacy Layout. Flag-on (`?next=1`) shows the canvas
  shell (CanvasShell) and is the **post-flip future**. `[flag-off]` findings hurt
  live users **now**; `[flag-on]` findings are pre-flip debt; `[both]` renders the
  same in either shell (page content with no `isNextDesign` branch — its frame is
  audited under the Shell section).
- **Scope** — every registered page + the two shells + the public landing. The V2
  onboarding screens are **excluded from deep audit** (about to be rebuilt in
  Phase 1); one-line notes only, at the end.
- **Method** — 7 parallel domain audits against the 9-rule bar, both flag states.
  Blockers on live-visible surfaces were spot-verified against source by the
  synthesizer (Profile reorder, landing AA + dropzone, Subagents AA all
  ground-truthed).

## Cross-cutting themes (fix once, resolve many)

1. **`focus-visible` is the single biggest systemic gap.** The flag-off legacy
   shell + Home, the 3 admin/utility tab systems, CV Studio (~2 of ~20 controls
   ringed), StoryBank (0), and several flag-on controls (home tabs, carousel
   chevrons, "Add manually", "Show more") lean on the UA default outline. One
   shared focus-ring utility applied to the button/link primitives closes most of
   these. _(Rule 5.)_
2. **No error/danger color token exists** since coral retired. Consequences show
   up as real bugs: flag-on CV "save failed" pill renders in brand slate
   (`rd-primary`), Settings "Delete account" looks identical to a primary Save,
   Home/CvMatchedRolesRail error states read as info chips, Home error banner
   inlines raw red hex. **Introduce `--rd-error-*` (a red trio that survives
   flag-on)** and route all failure/destructive affordances through it. _(Rules 1,
   5, 9.)_
3. **Sub-AA faint-grey text recurs across legacy surfaces** — `#A3A3A3` (~2.6:1)
   on white in Admin/AdminLaunch/Subagents, `#A39A8C` (`--ink-faint`, ~2.6:1) on
   cream across the public Landing, `rd-text-tertiary` self-documented sub-AA in
   flag-on. A token-level fix (darken the muted/tertiary values) clears the whole
   class. _(Rule 8.)_
4. **Token/type drift is universal and known** — ad-hoc `text-[Npx]`,
   `rounded-[Npx]`, one-off hex on nearly every file. Already slated for the
   type/space-scale pass; summarized once per file below, **not** enumerated. This
   is the largest single item but the lowest-severity — it's the "vibe-coded tell"
   to retire wholesale, not a launch blocker.
5. **Touch targets under 44px** recur on mobile controls (legacy mobile close,
   sign-out, CanvasMobileRail 36px nav, CV Studio chevrons/×, landing nav pills).
   _(Rule 8.)_
6. **Tab visual language is inconsistent** across sibling pages (Profile fills
   `rd-text`, Calendar/Internship fill `rd-primary`, LinkedIn underline, Home
   segmented pill) — converge on one tab component. _(Rule 4.)_
7. **False-empty flash from a missing `isLoading` guard** — a query whose `data`
   defaults to `[]` renders its "nothing here" empty state for one frame before
   the fetch resolves, so returning users briefly see "No applications yet" /
   zero funnels. Confirmed on HomeTrackerTab (flag-on), Career Pipeline, and the
   Tasks category-filter (which has _no_ filtered-empty state at all → a blank
   void). Pattern fix: gate every empty branch on a resolved query + a skeleton.
   _(Rule 7.)_
8. **Flag-on theme-tracking failures** — chat surfaces hardcode flag-off hex
   (`bg-[#211D18]`, `bg-[#F3ECE0]`) that equal the flag-off tokens but diverge
   under the flag, so on a flag-on canvas the message bubbles + typing indicator
   render in flag-_off_ colors; and `rd-text-tertiary` (self-documented sub-AA
   `#a6957f` flag-on) carries meaningful descriptive copy across chat/jobs/coach.
   Both resolve by using tokens + bumping meaningful copy off the tertiary tier.
   _(Rules 1, 8.)_
