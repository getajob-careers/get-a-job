# Archive

Point-in-time snapshots from earlier in the project — old session summaries, a pre-demo plan, an early bug list, a skills audit, and a project brief written for handing off to a fresh AI session.

**These are historical and are never updated.** They explain how the codebase got to its current shape, but they are *not* authoritative about how things work now. When an archived doc disagrees with the code or the [handbook](../README.md), the code wins.

Kept for history and context. If you're looking for current information, start at the [handbook home](../README.md).
