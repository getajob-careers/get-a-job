# Session Handoffs

One file per working session between Eli, Claude.ai, and Claude Code. Newest file = most recent state.

**Important caveat: these are historical snapshots, not current truth.** Many contain facts that were later corrected or superseded (user counts, pilot structure, the ESCO adoption that was later demoted, PRs that were replaced). They are preserved uncorrected as the project's history. Current truth lives in the team handbook under `docs/`; volatile counts belong to generated facts, never prose.

Naming: `session-handoff-YYYY-MM-DD[-suffix].md`. Files originally named loosely (e.g. `handoff_20_05_26`) were renamed to this scheme on import (2026-07-06). Note: the file originally named `handoff_july_23rd_2026` was renamed to `session-handoff-2026-06-23.md` - its content sits between the June 22 and June 24 sessions; the original name was a typo.
